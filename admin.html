How this dashboard works

This site's content lives in a Supabase database, not in files on GitHub:

  • Signing in uses real authentication (Supabase Auth) — your email and password are checked by Supabase, not stored in this site's code.
  • Save changes writes directly to the live database. Every visitor sees your changes immediately — there's no separate "publish" step.
  • Upload photo uploads the real file to Supabase Storage and uses it right away.
  • Only accounts you've explicitly added in Supabase (Authentication → Users) can sign in and save changes. Everyone else can only view the public site.
  • Export content.json and Import JSON are optional convenience tools for taking a backup or bulk-restoring one — not required for normal editing.
